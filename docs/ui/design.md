# KasirKu — Design System

## Brand & Personality

KasirKu adalah aplikasi Point of Sale (POS) modern, cepat, andal, dan ramah pengguna dengan nuansa visual kontras tinggi yang jelas dan efisien untuk operasional kasir dan toko.

## Colors

- Primary: #FFC61A (Warna aksen utama, tombol aksi utama, penanda aktif)
- Primary Hover / Dark: #E5B214
- Text Main: #232323 (Teks utama, heading, kontras tinggi)
- Text Secondary / Muted: #666666
- Error: #C62828 (Status error, pembatalan transaksi, stok habis)
- Success: #2E7D32 (Transaksi berhasil, status aktif)
- Surface / Background: #F8F9FA
- Surface Card / Container: #FFFFFF
- Border / Outline: #E0E0E0

## Typography

- Heading Font: Poppins, sans-serif (Bold, 600-700)
- Body Font: Inter, sans-serif (Regular 14px, 400; Medium 500)
- Scale:
  - H1: 28px / Bold
  - H2: 22px / Bold
  - H3: 18px / SemiBold
  - Body: 14px / Regular
  - Caption / Small: 12px / Medium

## Spacing & Shape

- Base spacing unit: 8px (skala: 8px, 16px, 24px, 32px, 40px)
- Border Radius: 8px (cards, buttons, input fields, badges)
- Elevation / Shadow: Soft diffused elevation for active cart/order panels and elevated cards.
